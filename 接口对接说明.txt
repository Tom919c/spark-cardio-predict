【阅读须知】
1. 前端当前为 IS_MOCK = true，所有数据走内置 Mock，不发起真实请求。
   对接时后端只需按下方"接口清单"逐一提供接口即可，无需改动前端任何其他代码。
2. 前端统一约定：真实接口返回外层包 { "code": 200, "message": "ok", "data": {...} }，
   前端取 respData.data 渲染；code !== 200 视为失败并弹错误框。
3. 切真实后端方法：把两页面对应的 IS_MOCK 改为 false，并把 API_BASE(_URL)
   改成 D 的服务地址（默认占位 http://127.0.0.1:5000）。
   - B端.html 第552-553行：const IS_MOCK = true; const API_BASE_URL = 'http://127.0.0.1:5000';
   - C端.html 第665-667行：const IS_MOCK = true; const API_BASE = 'http://127.0.0.1:5000';
                            const MODEL_PATH = 'models/best_model.pkl';
4. 字段命名全部使用 snake_case，与下方示例保持一致即可（首屏无需改字段名）。

================================================================================
一、B端大屏（templates/B端.html）
================================================================================
数据入口：fetchData(endpoint)，endpoint ∈ { summary, profile, map, preprocess }
说明：map 端点无后端接口（前端直接拉取阿里 DataV 全国 GeoJSON，见下）。

--------------------------------------------------------------------------------
接口 1：区域风险概览（顶部统计卡）
--------------------------------------------------------------------------------
- endpoint: summary
- 真实请求：GET  {API_BASE_URL}/api/risk/summary
- 返回 data 结构（与 MOCK.overview 一致）：
  {
    "total_screening_count": 128476,     // 累计筛查人数（整数）
    "high_risk_count": 23489,            // 高危人数（整数）
    "avg_disease_probability": 18.6,     // 平均患病概率 %（浮点）
    "pending_followup_count": 8723       // 待随访人数（整数）
  }

--------------------------------------------------------------------------------
接口 2：社区人群画像（雷达图 + 风险词云）
--------------------------------------------------------------------------------
- endpoint: profile
- 真实请求：GET  {API_BASE_URL}/api/data/profile
- 返回 data 结构（与 MOCK.community_profile 一致）：
  {
    "radar": {                            // 雷达图 5 维（0-100 分值）
      "avg_risk_score": 68.5,             // 平均风险评分
      "hypertension_rate": 32.4,          // 高血压率 %
      "obesity_rate": 28.7,               // 肥胖率 %
      "smoking_rate": 35.2,               // 吸烟率 %
      "insufficient_exercise_rate": 42.1  // 运动不足率 %
    },
    "word_cloud": [                       // 词云：风险因子
      { "factor_name": "高血压", "weight": 85 },
      { "factor_name": "高血脂", "weight": 72 }
      // ... 每项 factor_name(字符串) + weight(整数权重)
    ]
  }

--------------------------------------------------------------------------------
接口 3：地图风险分布（全国省级热力）
--------------------------------------------------------------------------------
- endpoint: map
- 真实请求：无（前端直接 fetch 阿里 DataV 公共 GeoJSON）
  URL: https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json
- 返回 data 结构（前端内置 MOCK.map_data，后端若自行提供同名接口可返回如下数组）：
  [
    { "province": "北京市", "risk_value": 42.3, "risk_level": 3 },
    { "province": "四川省", "risk_value": 51.2, "risk_level": 3 }
    // province: 省/直辖市/特别行政区全称；risk_value: 风险均值%(浮点)；risk_level: 1-5 整数
  ]
- 注：为减少后端工作量，地图默认走公共 GeoJSON + 前端内置数据；该端点当前 urlMap 为 null。

--------------------------------------------------------------------------------
接口 4：特征权重 + 年龄金字塔 + 随访名单（合并返回）
--------------------------------------------------------------------------------
- endpoint: preprocess
- 真实请求：GET  {API_BASE_URL}/api/data/preprocess
- 返回 data 结构（与 MOCK 三块合并一致）：
  {
    "feature_importance": [               // 特征重要性 Top10（横向柱状图）
      { "feature_name": "年龄", "importance": 22.5 },
      { "feature_name": "收缩压", "importance": 18.3 }
      // feature_name(字符串) + importance(浮点权重)
    ],
    "age_pyramid": [                      // 年龄金字塔（男女各年龄段高危人数）
      { "age_group": "18-29岁", "male_count": 156, "female_count": 112 },
      { "age_group": "30-39岁", "male_count": 823, "female_count": 645 }
      // age_group(字符串) + male_count(int) + female_count(int)
    ],
    "follow_up_list": [                   // 随访名单（已脱敏）
      {
        "name": "张**", "age": 68,
        "community": "锦江区-东湖社区",
        "probability": 82.5,              // 风险概率 %(浮点)
        "risk_level": 5,                  // 1-5 整数
        "followup_note": "7日内紧急随访"   // 随访建议文案
      }
    ]
  }

二、C端个人评测页（templates/C端.html）
================================================================================
数据入口：表单提交 → POST /api/risk/predict

--------------------------------------------------------------------------------
接口 5：个人风险评估预测
--------------------------------------------------------------------------------
- 真实请求：POST  {API_BASE}/api/risk/predict
- 请求头：Content-Type: application/json; Accept: application/json
- 请求体（model_path + 全部 DWD 标准体检字段，与表单 1:1 对应）：
  {
    "model_path": "models/best_model.pkl",   // 固定传模型路径
    "age": "50",                              // 年龄(岁) 字符串，范围 20-100
    "gender": "0",                            // 性别 0=女 1=男（单选）
    "height": "170",                          // 身高(cm) 范围 140-220
    "weight": "65",                           // 体重(kg) 范围 30-200
    "sbp": "120",                             // 收缩压(mmHg) 范围 80-240
    "dbp": "80",                              // 舒张压(mmHg) 范围 50-160
    "cholesterol": "4.5",                     // 总胆固醇(mmol/L) 范围 2-10
    "glucose": "5.0",                         // 空腹血糖(mmol/L) 范围 2-20
    "hypertension": "0",                      // 高血压史 0/1（单选）
    "diabetes": "0",                           // 糖尿病史 0/1（单选）
    "smoking": "0",                            // 吸烟 0=不吸 1=偶尔 2=经常（单选）
    "alcohol": "0",                            // 饮酒 0/1（单选）
    "exercise": "0",                           // 运动 0/1（单选）
    "family_history": "0",                     // 家族病史 0/1（单选）
    "bmi": null                                // 由前端用身高体重计算，可不传
  }
  说明：前端所有输入均为字符串（表单值），后端按需要自行转数值；bmi 前端已算好传回。

- 返回 data 结构（与 generateMockResult 完全一致，重点对齐以下字段）：
  {
    "risk_prob": 72.6,          // 风险概率 %(浮点，0-100)
    "risk_level": "Ⅳ级：深橙高危",  // 分级中文文案（见下方 Ⅰ-Ⅴ 文案表）
    "level_class": "level-4",   // 样式类名 level-1 ~ level-5（前端据此取色）
    "color": "#EA580C",         // 该级代表色（十六进制）
    "guide_text": "危险程度高，建议遵医嘱配合降压/降脂药物干预...",  // 健康指导长文案
    "suggestions": [            // 个性化建议数组
      { "type": "goal", "title": "体重管理目标", "desc": "您的BMI为..." },
      { "type": "warn", "title": "血压控制提醒", "desc": "..." }
      // type ∈ goal/warn/diet/activity/med；title(字符串)+desc(字符串)
    ]
  }

- C端 5 级分级文案与配色（与 level_class / color 对应）：
    level-1  Ⅰ级：绿色健康     #22C55E   风险 < 15%
    level-2  Ⅱ级：黄色关注     #EAB308   风险 15%-35%
    level-3  Ⅲ级：橙色中危     #F97316   风险 35%-60%
    level-4  Ⅳ级：深橙高危     #EA580C   风险 60%-80%
    level-5  Ⅴ级：红色极高危   #EF4444   风险 ≥ 80%

四、本地运行方式
================================================================================
方式A（最简单）：直接双击打开 templates/B端.html 或 templates/C端.html
                 （依赖 CDN：Tailwind / ECharts / echarts-wordcloud，需联网；当前 IS_MOCK=true 自带数据）
方式B（本地服务器，推荐）：在项目根目录执行
                 python -m http.server 8000
                 浏览器访问 http://127.0.0.1:8000/templates/B端.html
                       http://127.0.0.1:8000/templates/C端.html
注：本交付包为纯前端静态文件，static/ 仅作目录占位（当前为空），不含任何本地依赖。
