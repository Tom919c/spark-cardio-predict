# 阶段一整理记录

- 统一为心脏事件、卒中两个独立随机森林模型。
- 统一数据分层为 ODS、DWD、DWS、ADS。
- 移除代码中的本机绝对路径和固定 HDFS 地址，改为 `.env` 配置。
- B/C 端改为消费真实 Flask API，不保留 Mock 数据。
- 增加模型注册、群体分析、高危筛查和自动化测试。
- Spark 作业统一使用 ETL/特征结果作为后续分析输入，保留群体分析字段。
- 增加人口数据缓存、空数据保护和数据接口异常测试。
- 增加训练耗时估算、卒中拟合子集受控过采样、非法个人输入校验和模型清单损坏保护。
- B 端随访列表明确使用仿真标签筛查评分，不把标签评分伪装成个人模型发病概率。

## 阶段二初始实现记录

- 增加 SQLite 任务/数据集 DAO、分片上传、任务状态和本地/HDFS 访问抽象。
- 增加本地分块分析、区域覆盖识别、成都区县 GeoJSON、快照比较和批量双模型评估。
- 增加 What-if 情景模拟、模型/解释器缓存、候选模型离线评估和本地 JSON 健康建议规则。
- 前端增加上传进度、任务轮询、动态区域降级、快照图和本地 ECharts/地图资源。
- 上传数据不自动训练或替换正式模型，社区小样本结果执行匿名化保护。
- 单区县或单社区数据明确降级为表格，上传分析完成后前端读取并展示本次 ADS 汇总结果。
- WebHDFS 适配真实 `InsecureClient.status` 接口，支持 DataNode 重定向主机覆盖和 HDFS 合并文件长度校验。
- Spark 阶段二入口输出与本地分析一致的区域、年龄段、危险因素和隐私抑制摘要；缺少 `hdfs` Python 包时使用 Hadoop 原生 FileSystem 写入 JSON。
- 增加 Windows Flask 通过 `wsl.exe` 提交 WSL2 Spark 作业的配置桥接，个人 Linux 路径仅允许写在本机 `.env`。
