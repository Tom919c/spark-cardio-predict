# 模型设计

阶段一固定训练两个独立的 `RandomForestClassifier`：

| 模型 | 标签 | 输出 |
| --- | --- | --- |
| 心脏事件模型 | `label_heart` | 心脏事件概率 |
| 卒中模型 | `label_stroke` | 脑卒中概率 |

训练特征为年龄、性别、BMI、胆固醇、糖尿病、高血压、吸烟、饮酒和运动。缺失值使用 `IterativeImputer`；中国/四川/成都数据权重为 `4.0`，其他数据为 `1.0`；模型输出使用 `IsotonicRegression` 校准。

个人整体等级取两个概率中的最大值：小于 15%、15%~35%、35%~60%、60%~80%、80% 以上分别对应 I~V 级。
