# 模型设计

当前正式版本训练两个独立的 `XGBClassifier`：

| 模型 | 标签 | 输出 |
| --- | --- | --- |
| 心脏事件模型 | `label_heart` | 心脏事件概率 |
| 卒中模型 | `label_stroke` | 脑卒中概率 |

训练特征为年龄、性别、BMI、胆固醇、糖尿病、高血压、吸烟、饮酒和运动。
数据先切分为拟合、校准和测试子集，`IterativeImputer` 只在拟合子集上训练，
再转换校准集和测试集，避免测试集信息进入预处理参数。模型输出使用
`IsotonicRegression` 校准，并为心脏与卒中分别选择满足召回率要求的决策阈值。

当前标签由公开数据中的危险因素结合可复现规则生成，属于“风险筛查代理标签”。
因此模型概率只用于课程项目的风险排序和健康提示，不能解释为临床诊断概率、
真实年度发病率或经过外部临床验证的中国人群风险。

正式 XGBoost 版本保持自然阳性率，不执行过采样。校准集和测试集均保持自然标签比例。

个人整体等级取两个概率中的最大值：小于 15%、15%~35%、35%~60%、60%~80%、80% 以上分别对应 I~V 级。
