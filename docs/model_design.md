# 模型设计

阶段一固定训练两个独立的 `RandomForestClassifier`：

| 模型 | 标签 | 输出 |
| --- | --- | --- |
| 心脏事件模型 | `label_heart` | 心脏事件概率 |
| 卒中模型 | `label_stroke` | 脑卒中概率 |

训练特征为年龄、性别、BMI、胆固醇、糖尿病、高血压、吸烟、饮酒和运动。缺失值使用 `IterativeImputer`；当混合训练表提供 `region` 字段时，中国/四川/成都数据权重为 `4.0`，其他数据为 `1.0`；当前 11 列 DWD 表不含 `region`，因此本次训练全部使用 `1.0` 权重。模型输出使用 `IsotonicRegression` 校准。

卒中标签稀少时，仅对随机森林的拟合子集进行受控的阳性样本过采样；校准集和测试集保持自然患病率，避免评估指标虚高。当前实现是基于真实阳性样本的有放回抽样，不宣称生成了新的临床病例。

个人整体等级取两个概率中的最大值：小于 15%、15%~35%、35%~60%、60%~80%、80% 以上分别对应 I~V 级。
